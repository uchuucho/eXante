## Overview

eXante forecasts future prices of critical EV battery metals and evaluates the impact of geopolitical, policy, and mining-related shocks on market dynamics.

The system combines:
- IMF historical metal price data (112 months)
- Sybilion API for probabilistic 6-month forecasting
- OLS regression shock model fitted on crisis event data
- Log-return signal-to-noise decision engine
- Live web dashboard with scenario analysis

## Data

For each metal, the dataset contains monthly historical market prices from January 2017 to April 2026. We identified key geopolitical events, policy changes, and mining/supply disruptions that affected prices, and encoded them as three continuous scores:

- **G** — Aggregated geopolitical score
- **P** — Aggregated policy score  
- **M** — Aggregated mining/supply score

Each score is a weighted sum of dated events with weights chosen to reflect their estimated price impact. Values range from 0 to 1.

### Example: Cobalt Geopolitical Events

| Event | Timeline | Weight |
|-------|----------|--------|
| DRC political instability baseline | 2016-01 → ongoing | 0.30 |
| Ethical sourcing / ESG scrutiny | 2018-01 → ongoing | 0.20 |
| COVID supply chain disruption | 2020-03 → 2021-12 | 0.15 |
| Africa logistics and DRC instability spike | 2022-01 → ongoing | 0.25 |
| Resource nationalism in Africa | 2024-01 → ongoing | 0.10 |

Full event tables for all metals and all three factors (G, P, M) are documented in `data/metals.xlsx`.

## Methodology

### 1. Baseline Forecasting

Future prices are obtained from the Sybilion API. For each 6-month horizon the system receives:
- Predicted price (p50 median)
- Confidence interval (p10 / p90 quantiles)
- Forecast uncertainty

### 2. Shock Modeling

The influence of external shocks is modeled using OLS log-linear regression:

```
log(P_t) = β₀ + βG·G_t + βP·P_t + βM·M_t
```

where G, P, M are the aggregated shock scores. Interaction terms were tested but removed due to multicollinearity. The regression is fitted on the full historical dataset per metal and coefficients are stored in `data/betas.json`.

The shock adjustment applied to the Sybilion baseline forecast:

```
P_adj = P_base × exp(shock)
shock = βG·G + βP·P + βM·M
```

### 3. Expected Return Estimation

Let P₀ denote the current price (April 2026) and P_t the forecasted future price. The expected log-return is:

```
r_t = log(P_t) - log(P₀)
μ = Σ r_t
```

### 4. Risk Estimation

Forecast confidence intervals are converted into per-period volatility estimates:

```
σ_t = (log(p90_t) - log(p10_t)) / (2 × 1.96)
σ = sqrt(Σ σ_t²)
```

### 5. Decision Rule

The system generates Buy/Hold/Wait recommendations using a signal-to-noise ratio:

```
SNR = μ / σ

Buy now     → SNR ≥ 0.3, σ < 0.4
Buy partial → SNR ≥ 0.3, σ ≥ 0.4
Hold        → SNR ≥ 0.0
Wait        → SNR < 0.0
```

A conviction score (0–100%) reflects confidence adjusted for active shocks.

### 6. Scenario Analysis

Three pre-computed shock scenarios are available per mineral:
- **Geopolitical shock** (G = 0.25)
- **Policy change** (P = 0.25)
- **Mining issue** (M = 0.25)

Each scenario grid is computed at pipeline run time using the fitted betas and stored in the output JSON. The dashboard does instant lookup — no live API calls during the demo.

## Usage

### Step 1 — Fit shock regression (run once, or when metals.xlsx changes)
```bash
python3 shock_model.py
# Writes ../data/betas.json
```

### Step 2 — Run full pipeline
```bash
python3 sybilion_ev_minerals.py
# Fetches Sybilion forecasts, applies betas, writes ../data/ev_minerals_results.json
```

### Step 3 — Launch dashboard
```bash
cd ..
python3 -m http.server 8000
# Open http://localhost:8000
```

---

## Limitations

- Regression coefficients do not imply causality.
- G, P, M scores are approximate weighted constructions — not formal econometric indices.
- Historical relationships may change over time.
- Forecast quality depends on Sybilion API accuracy.
- Interaction terms (GP, GM, PM) were excluded due to multicollinearity.
